## IndexTTS-2

Blocked, no clips. Two failures, then a crash loop that is now stopped.

- First try (third-party `indextts2-inference` wrapper): model loaded in 126 s, 8.21 GB VRAM, then inference crashed in the GPT forward, `AttributeError: 'NoneType' object has no attribute 'shape'`, because the wrapper targets transformers 5.x, whose beam search passes attention_mask=None.
- Second try (official `index-tts` repo, transformers 4.52.1, torch 2.8): the image built fine, but the function container could never start. Modal retried the start every few seconds from 22:01:33 UTC and emailed Nicholas about the crash loop at 2:16 PM PST. The bridge run driving it was cancelled, and the app stopped at 22:26:07 UTC. No containers are running now.
- Exact startup error, from the run log:
  `AttributeError: Enum VolumeFsVersion has no value defined for name 'ValueType'`
  `Function fu-vPK0ggx1KmqQi3MkO4vIKK failed during startup.`
- Likely cause, not yet proven: the official repo install downgraded protobuf to 3.19.6 inside the image (earlier working images had protobuf 4.25.0), and the Modal container runtime's own import chain then fails on the VolumeFsVersion enum before any user code runs. Do not redeploy IndexTTS-2 until this is confirmed. A possible fix to test later is pinning protobuf>=4 after the official install.

## Build problems fixed along the way (kept here so they are not re-debugged)

- Modal image builds fail if `add_local_file` is not the last step; it now is.
- CosyVoice requirements fail on a modern toolchain because openai-whisper's setup.py imports pkg_resources (removed in setuptools 81). Whisper is installed separately with `--no-build-isolation` against setuptools<81. It is genuinely needed: the frontend calls `whisper.log_mel_spectrogram` on the prompt clip.
- DeepSpeed breaks the import chain (transformers imports it, it tries to compile CUDA ops with no CUDA toolkit in the image). It is uninstalled in the CosyVoice and IndexTTS images; it is only used for training.
- `matcha` comes from the CosyVoice repo's `third_party/Matcha-TTS` git submodule and needs to be on PYTHONPATH.
- `modal volume get` of a directory fails with Errno 21 unless the destination directory already exists. The fetch step now creates it first, with a per-file fallback.
