## Serena, softer voice, same HSK 3 set

Nicholas asked for a softer voice after hearing Vivian. Selection: Serena, the softer Chinese female preset in the same Qwen3-TTS 1.7B CustomVoice model, described in the official Qwen3-TTS model card as a warm, gentle young female voice. Vivian is described there as bright, slightly edgy young female. Same model, same language Chinese, same instruct "用自然平稳的语气朗读。", same T4 GPU, same h01-h06 sentences. Only the speaker changed.

Code change, commit 7cd83ae: the Qwen speaker is now a `--speaker` parameter on `modal_app.py` (default Vivian), and `run_via_bridge.sh` takes it as a third argument. A non-Vivian speaker writes to its own output folder, so Serena clips cannot overwrite the Vivian clips.
